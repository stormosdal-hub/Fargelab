Fram og tilbake

OpenCV lagrer farger som BGR

Bilder fra cv2.imread har blå kanal først. Nettet og de fleste andre verktøy bruker RGB, så hex-koden øverst står i RGB-rekkefølge.

H går bare til 179

Nyansen er en vinkel fra 0° til 360°, men en uint8 rommer bare 0–255. OpenCV deler derfor vinkelen på 2. Med COLOR_BGR2HSV_FULL får du 0–255 i stedet.

Rødt ligger i begge ender

Rød nyanse finnes både nær H = 0 og nær H = 179. Skal du finne røde områder med cv2.inRange, trenger du ofte to masker som du slår sammen.

S og V kan gjøre H meningsløs

Når V er 0 er fargen svart, og når S er 0 er den grå. Da spiller H ingen rolle, og verdiene kommer ikke nødvendigvis tilbake hvis du går via BGR.

Uten OpenCV.js regner siden med en JavaScript-kopi av OpenCVs 8-bits algoritme (js/hsv-kopi.js). Den er kontrollert mot OpenCV.js 4.10 for alle 16,7 millioner BGR-farger og alle HSV-kombinasjoner, også gråtonen. Du kan kjøre kontrollen selv med node test/sammenlign.js.

Python med OpenCV

Skriv Python-skript med OpenCV, numpy og matplotlib, og kjør dem rett i nettleseren. Python kjører i Pyodide, som er Python kompilert til WebAssembly.

Python startes når du åpner denne fanen.

skript/

Skriptet lagres bare i nettleseren nå. Start siden med python server.py i prosjektmappen, så kan du lagre skript og notatbøker i mappen skript/ og bruke bildene i bilder/.

Filer

Skriptet kjører i mappen /home/pyodide. Bildet du åpner i Fargelab-fanen havner her, så cv2.imread('navn.png') virker. Du kan også slippe filer på denne fanen. Filer skriptet lagrer, for eksempel med cv2.imwrite, kan du laste ned.

Alt i mappen bilder/ i prosjektet ligger der skriptet kjører, så cv2.imread('navn.jpg') virker uten sti. Nye bilder du legger i mappen, er med neste gang du trykker Kjør. Filer du legger til her eller slipper på fanen, lagres i bilder/. Filer skriptet lagrer, for eksempel med cv2.imwrite, kan du lagre i bilder/ eller laste ned.

  • Filene vises når Python har startet.

Bilder vises under Utdata

cv2.imshow(navn, bilde) og plt.show() viser bildene under Utdata. cv2.waitKey og cv2.destroyAllWindows gjør ingenting. Figurer du ikke har vist, kommer til slutt. Med cv2.setMouseCallback kan du klikke i bildene.

Hent verdier fra Fargelab

import fargelab gir fargelab.bgr, fargelab.hsv, fargelab.bilde (filnavnet) og fargelab.piksel (x, y), slik de står i Fargelab-fanen når du trykker Kjør. fargelab.bilder er en liste over filene i bilder/.

Flere pakker

Pakker som følger med Pyodide, for eksempel scipy, pandas og scikit-image, lastes automatisk når skriptet importerer dem. Andre rene Python-pakker kan du hente med micropip.

Det som ikke virker

input(), tkinter og wxPython virker ikke i nettleseren. Bruk widgets i stedet: @interact, ipywidgets eller cv2.createTrackbar. Løkker med cv2.waitKey henger, så skriv dem med en callback. Stopp starter Python på nytt, og da forsvinner filer skriptet har laget. Filer du har lagt til selv, blir lagt inn igjen.
